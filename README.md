# epub-reader
편한 EPUB 리더 - 휴대폰·컴퓨터용 전자책 보기 웹앱 (PWA)

## 등산 지도 (`hiking/`)
휴대폰·컴퓨터용 등산 지도 웹앱 (PWA). GitHub Pages로 배포하면 `…/epub-reader/hiking/` 주소로 열리며, 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

- 지도: 지형도(등고선, OpenTopoMap) · 일반 지도(OpenStreetMap) · 위성 사진(Esri) + 등산로 겹쳐 보기(Waymarked Trails)
- 내 위치 따라가기, 휴대폰 방향(나침반) 표시, GPS 정확도 표시
- 산행 기록: 시작·일시정지·종료, 거리·시간·오른 높이·현재 고도, 기록 중 화면 켜짐 유지, 앱이 닫혀도 진행 중 기록 복구
- 내 산행 기록 목록, 고도 그래프(그래프를 훑으면 지도에 위치 표시), GPX 내보내기
- GPX 불러오기(파일 선택·끌어다 놓기·안드로이드 파일 열기)
- 지도 길게 눌러 지점 저장·좌표 복사, 직선거리 재기
- 산·장소 검색(OpenStreetMap Nominatim), 일몰까지 남은 시간 표시, 내 위치 보내기
- 단위 전환(km·m ↔ mi·ft), 한 번 본 지도 타일 오프라인 캐시
- 기록·지점은 이 기기(브라우저)에만 저장됩니다. Leaflet 1.9.4는 `hiking/vendor/`에 포함(BSD-2-Clause).
